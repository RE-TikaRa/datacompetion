## 2026-11-08：机会判别接口试运行

模型服务使用现有 Codex 配置中的 `gpt-6.1-sol`，通过 Codex 当前 Responses API 服务及本机凭据调用。密钥没有写入项目文件。具体地址、成本单价和转发服务计费规则没有写入报告；费用因此标为未知。

用途是测试机会判别结构、四项条件、官方分类标签和逐字证据检查。模型看到 7 条公开文本作为试运行记录：先 2 条 GitHub 项目，再选 GitHub、Hacker News、IT之家、量子位、V2EX 各 1 条。后 5 条请求耗时约 72 秒，服务用量为 4,706 输入 token、1,272 输出 token；2 条请求用量为 1,130 输入 token、1,189 输出 token。结果保存在本地忽略的 `results/` 目录，不作为人工标注或最终验证数据。

生成内容用于判断代码是否能返回四项条件、标签和原文摘句。程序从“存在可观察需求、AI 为核心、技术可实现、无排除项”派生机会标签，并验证摘句确实出现在原文中。试运行记录全部被判为非机会，原因涵盖产品说明缺少明确需求、AI 并非核心、新闻转述及宣传内容。confidence 是模型自评，尚未校准。
